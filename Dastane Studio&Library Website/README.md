## 📖 نیا ناول کیسے شامل کریں؟ (How to Add a New Novel)

آپ کو `index.html` یا `style.css` میں کچھ بھی تبدیل کرنے کی ضرورت نہیں ہے۔ صرف **`js/data/novels.js`** فائل کو اوپن کریں:

### طریقہ کار (Step-by-Step):
1. فائل اوپن کریں: `js/data/novels.js`
2. `novelsData` والی بریکٹ کے اندر نیچے دیے گئے کوڈ جیسا ایک نیا بلاک شامل کریں:

```javascript
    {
        id: 4,
        title: "آپ کے نئے ناول کا نام",
        tag: "Romantic Suspense", // یا Featured Novel / Short Story وغیرہ
        description: "یہاں ناول کا مختصر خلاصہ لکھیں۔",
        buttonText: "Read Online",
        isAvailable: true, // اگر ناول پڑھنے کے لیے تیار ہے تو true، ورنہ false
        link: "#", // اگر ناول کا پی ڈی ایف یا لنک ہو تو وہ یہاں درج کریں
        alertMessage: "",
        coverImage: "" // اگر تصویر لگانی ہو تو جیسے "assets/images/cover1.jpg"
    },
```

3. فائل کو محفوظ (Save) کریں اور براؤزر میں پیج ریفریش کریں۔ نیا کارڈ خوبصورت اینیمیشن کے ساتھ خود بخود ویب سائٹ کے لائبریری سیکشن میں نظر آ جائے گا!

## 🎨 رنگ اور تھیم تبدیل کرنا (Styling & Colors)

اگر آپ ویب سائٹ کا بنیادی رنگ یا بیک گراؤنڈ بدلنا چاہتے ہیں تو **`css/style.css`** کی پہلی چند لائنوں میں `:root` اور `[data-theme="dark"]` کے متغیرات (variables) کو تبدیل کر سکتے ہیں:

```css
:root {
    --bg-color: #fcfbf7;        /* لائٹ موڈ بیک گراؤنڈ */
    --text-color: #2c2520;      /* لائٹ موڈ ٹیکسٹ کلر */
    --accent-color: #6b1d2f;    /* بنیادی برانڈ کلر (Burgundy/Maroon) */
}
```

## ⚙️ دیگر فیچرز (Included Features)
- **ڈارک / لائٹ موڈ (Dark & Light Mode):** صارف کی ترجیح براؤزر میں خودکار محفوظ رہتی ہے۔
- **موبائل ریسپانسو مینو (Mobile Responsive Hamburger Menu):** تمام موبائل اور ٹیبلٹس پر بہترین کام کرتا ہے۔
- **اسکرول اینیمیشنز (Scroll Reveal Animations):** نیچے اسکرول کرتے وقت تمام کارڈز اور سیکشنز خوبصورتی سے ظاہر ہوتے ہیں۔
- **انٹرایکٹو کاؤنٹرز (Animated Statistics Counters):** 15+ کتب، 5K+ قارئین کے کاؤنٹرز آٹو اینیمیٹ ہوتے ہیں۔
- **انٹرایکٹو FAQ ایکارڈین (Accordion):** سوال پر کلک کرنے سے جواب کھلتا اور بند ہوتا ہے۔
