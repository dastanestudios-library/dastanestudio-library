📖 DASTANE STUDIO - NOVELS & SHORT STORIES ADDING GUIDE (ناول و افسانہ گائیڈ)
================================================================================

1️⃣ اگر نیا "ناول (Full Novel)" ایڈ کرنا ہو:
فائل کھولیں: js/data/novels-list.js
اور یہ بلاک کاپی کر کے آخر میں پیسٹ کریں:

{
    id: 6, // نیا نمبر
    title: "ناول کا نام",
    type: "novel",
    tag: "Featured Novel",
    categoryName: "Novel",
    description: "یہاں ناول کا مختصر خلاصہ لکھیں۔",
    buttonText: "Read Online",
    isAvailable: true,
    link: "https://your-novel-link.blogspot.com/",
    coverImage: "https://i.pinimg.com/...jpg"
},

--------------------------------------------------------------------------------

2️⃣ اگر نیا "افسانہ یا مختصر کہانی (Short Story)" ایڈ کرنا ہو:
فائل کھولیں: js/data/stories-list.js
اور یہ بلاک کاپی کر کے آخر میں پیسٹ کریں:

{
    id: 7, // نیا نمبر
    title: "کہانی کا نام",
    type: "story",
    tag: "Short Story",
    categoryName: "Short Story",
    description: "یہاں کہانی کا مختصر خلاصہ لکھیں۔",
    buttonText: "Read Online",
    isAvailable: true,
    link: "https://your-story-link.blogspot.com/",
    coverImage: "https://i.pinimg.com/...jpg"
},

--------------------------------------------------------------------------------
