================================================================================
📜 DASTANE STUDIO & LIBRARY - ASAN BLOGGER NOVEL TEMPLATE (Ultra-Easy Guide)
================================================================================
Aapke kehnay ke mutabiq is code ko nihayat aasan (super-easy) bana diya gaya hai!

Ab aapko paragraph banane ke liye kisi bhi <p> ya </p> tag lagane ki ZAROORAT NAHI HAI!
Aap InPage, MS Word, Notepad ya WhatsApp se apna pura Urdu novel copy karein aur
seedha paste kar dein. Jahan bhi aap Enter dabayenge, naya paragraph khud ban jayega!

Coding ke andar har cheez ko Roman Urdu mein clearly likh diya gaya hai ke:
1. Novel ka naam kahan likhna hai.
2. Episode number kahan likhna hai.
3. Tareekh kahan likhni hai.
4. Novel ka text kahan paste karna hai (Direct Paste).
5. Pichli aur agli qist ka link kahan lagana hai.
================================================================================

💡 Blogger Par Kaise Use Karein? (Sirf 3 Steps):
1️⃣ Blogger Dashboard mein "New Post" khol kar left corner par "HTML view (<>)" select karein.
2️⃣ Neeche diya gaya pura code copy kar ke wahan paste kar dein.
3️⃣ Code mein "👇 4. YAHAN APNA NOVEL PASTE KAREIN" ke neeche apna pura novel paste karein aur Publish kar dein!

      window.dsChangeFontSize = function(delta) {

      window.dsToggleTheme = function() {
        if (!root) return;
        if (root.classList.contains('ds-theme-dark')) {
          root.classList.remove('ds-theme-dark');
          root.classList.add('ds-theme-light');
          if (toggleBtn) toggleBtn.textContent = '🌙 Dark';

          root.classList.remove('ds-theme-light');
          root.classList.add('ds-theme-dark');
          if (toggleBtn) toggleBtn.textContent = '☀️ Light';
        }
      };
    })();
