📖 DASTANE STUDIO & LIBRARY - NOVELS & STORIES ADDING GUIDE (Roman Urdu Guide)

1️⃣ Agar Naya "Full Novel" Add Karna Ho:
File open karein: js/data/novels-list.js
Aur yeh block copy kar ke list mein add karein:

{
    id: 6, // Har novel ko naya unique ID number dein (maslan 6, 7, 8)
    title: "Novel Ka Naam",
    type: "novel",
    tag: "Featured Novel", // Ya Romantic / Mystery / Thriller
    categoryName: "Novel",
    description: "Yahan novel ka dilchasp aur tafseeli khulasa likhein.",
    buttonText: "Read Online",
    isAvailable: true, // Agar available hai to true, warna false
    hasLanguageSelection: false, // Agar Urdu/English pop-up chahiye to true karein
    link: "https://your-novel-link.blogspot.com/",
    coverImage: "https://i.pinimg.com/...jpg"
},

--------------------------------------------------------------------------------

2️⃣ Agar Naya "Afsana Ya Mukhtasar Kahani (Short Story)" Add Karni Ho:
File open karein: js/data/stories-list.js
Aur yeh block copy kar ke list mein add karein:

{
    id: 7, // Naya unique ID number
    title: "Kahani Ka Naam",
    type: "story",
    tag: "Short Story",
    categoryName: "Short Story",
    description: "Yahan kahani ka mukhtasar aur dilchasp khulasa likhein.",
    buttonText: "Read Online",
    isAvailable: true,
    link: "https://your-story-link.blogspot.com/",
    coverImage: "https://i.pinimg.com/...jpg"
},

--------------------------------------------------------------------------------
✨ Khudkaar Features (Automatic Library Features):
* Yeh tamam novels aur afsanay "All Publications" library mein automatically show hotay hain.
* "Novels" aur "Short Stories" tabs par click karne se khud filter ho jatay hain.
* "Live Search Bar" mein naam ya description search karne par foran mil jatay hain.
* Pagination 100% automatic hai: Pehle page par sirf 9 kitabein rehti hain, 10th kitaab khud Page 2 par shift ho jati hai!
