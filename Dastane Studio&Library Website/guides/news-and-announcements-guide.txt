💡 Jab bhi aap website par koi naya notice, khabar, ya novel release update lagana chahein:

1️⃣ File open karein:
   👉 js/data/news/news-list.js

2️⃣ List mein neeche diya gaya block copy kar ke shamil karein ya mojooda notice ko edit karein:

{
    id: 4, // Har news ko naya unique number dein (maslan 1, 2, 3, 4)
    title: "News Title (English Heading)",
    subtitle: "Urdu Unwan ya Sub-heading",
    tag: "Important Update • اہم اطلاع", // Badge tag
    tagType: "urgent", // urgent, update, release, feature
    date: "September 09, 2026", // Tareekh
    displayDuration: 8, // ⏱️ Kitnay seconds tak yeh news screen par chalegi (apni marzi ka time likhein: 6, 8, 10, 12)
    coverImage: "https://i.pinimg.com/...jpg", // Cover picture ka link
    highlightBadge: "📅 Release: 9 Sep 2026 • 8:00 PM", // Red highlight badge
    messageUrdu: "Yahan Urdu script mein tafseeli paigham likhein.",
    messageEnglish: "Here write the English announcement details.",
    actionText: "Read Online", // Button ka text
    actionLink: "https://thelastletterds.blogspot.com/2026/08/the-last-letter-dastane-studio.html" // Button ka link
},

--------------------------------------------------------------------------------
✨ 9:16 Story Box Ke Automatic Features:
1. ⏱️ Editable Time: Har news ka time (displayDuration in seconds) aap khud set kar saktay hain.
2. 🔄 Smooth Auto-Swipe: Timer khatam hotay hi agli news right-to-left automatically swipe ho jati hai.
3. 👆 Touch & Swipe: Mobile screen par reader ungli se left/right swipe kar ke pichli aur agli khabar dekh sakta hai.
4. ⏸️ Pause On Hover / Hold: Jab reader cursor layega ya mobile par ungli daba kar rakhega to timer pause ho jayega taake wo sakoon se khabar parh sake.
5. 📊 Top Story Progress Bars: Instagram stories ki tarah upar live progress bars chalti hain.
