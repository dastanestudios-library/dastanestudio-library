💡 جب بھی آپ نئی "آڈیو بک (Audiobook)" یا "صوتی ڈرامہ (Voice Story)" شامل کرنا چاہیں:

1️⃣ فائل کھولیں:
   👉 js/data/audiobooks/audiobooks-list.js

2️⃣ نیچے دیا گیا کوڈ کاپی کر کے لسٹ میں شامل کریں:

{
    id: 104, // ہر آڈیو بک کو نیا اور منفرد ID نمبر دیں (مثلاً 104, 105, 106)
    title: "ناول کا نام (Audio Edition)",
    type: "audiobook",
    tag: "Audio Drama", // یا Narrated Novel / Thriller Audio
    categoryName: "Audiobook",
    narrator: "صوتی پیشکش: داستان اسٹوڈیو",
    duration: "Available Soon", // یا وقت مثلاً "18:45"
    description: "یہاں صوتی کہانی کا دلچسپ تعارف اور تفصیل لکھیں۔",
    buttonText: "Available Soon...", // یا ریلیز کے بعد "Listen Audio" لکھیں
    isAvailable: false, // ریلیز کرنے کے لیے true کریں ورنہ false رہنے دیں
    alertMessage: "This audiobook will be available soon. Voice production is in progress!",
    audioSrc: "", // ریلیز کے وقت MP3 یا آڈیو فائل کا لنک لگائیں
    coverImage: "https://i.pinimg.com/...jpg" // کور تصویر کا لنک
},

--------------------------------------------------------------------------------
✨ لائبریری فلٹر سسٹم کے اصول (Library Rules):
1. "All Publications" میں آڈیو بکس مکس نہیں ہوں گی، وہاں صرف تحریری ناولز اور افسانے نظر آئیں گے۔
2. جیسے ہی قاری لائبریری کے "🎧 Audiobooks" والے ٹیب پر کلک کرے گا، تمام آڈیو بکس اپنے خصوصی کارڈز اور دورانیہ (Duration) کے ساتھ سامنے آ جائیں گی۔
3. جب تک `isAvailable: false` رہے گا، کارڈ پر "Available Soon..." آئے گا اور کلک کرنے پر نوٹس آئے گا۔
4. جیسے ہی آپ `audioSrc` کا لنک ڈال کر `isAvailable: true` کریں گے، قاری کے کلک کرنے پر نیچے "Floating Audio Player" چل پڑے گا!
