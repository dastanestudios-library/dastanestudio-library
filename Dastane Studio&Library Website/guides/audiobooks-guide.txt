💡 Jab bhi aap nayi "Audiobook" ya "Voice Drama (Soti Kahani)" add karna chahein:

1️⃣ File open karein:
   👉 js/data/audiobooks-list.js

2️⃣ Neeche diya gaya code block copy kar ke list mein add karein:

{
    id: 104, // Har audiobook ko naya aur unique ID number dein (maslan 104, 105, 106)
    title: "Novel Ka Naam (Audio Edition)",
    type: "audiobook",
    tag: "Audio Drama", // Ya Narrated Novel / Thriller Audio
    categoryName: "Audiobook",
    narrator: "Dastane Studio Voice Artists",
    duration: "Available Soon", // Ya time maslan "18:45"
    description: "Yahan audio kahani ka shandaar taruf aur tafseel likhein.",
    buttonText: "Available Soon...", // Release ke baad "Listen Audio" likhein
    isAvailable: false, // Release karne ke liye true karein, warna false rehne dein
    alertMessage: "This audiobook will be available soon. Voice production is in progress!",
    audioSrc: "", // Release ke waqt MP3 file ya audio stream ka direct link lagayein
    coverImage: "https://i.pinimg.com/...jpg" // Cover image ka direct URL
},

--------------------------------------------------------------------------------
✨ Library Filter System Ke Rules:
1. "All Publications" tab mein audiobooks mix nahi hotin, wahan sirf written novels aur afsanay aatay hain.
2. Reader jab "🎧 Audiobooks" wale tab par tap karega, to tamam audiobooks apne unique design aur duration badge ke sath samne aayengi.
3. Jab tak `isAvailable: false` rahega, button par "Available Soon..." aayega aur click karne par sweet message show hoga.
4. Jaise hi aap `audioSrc` link add kar ke `isAvailable: true` karenge, reader ke tap karte hi screen ke neeche sleek "Floating Audio Player" chalu ho jayega!
